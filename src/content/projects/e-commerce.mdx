# E-Commerce Platform

Platform e-commerce lengkap yang dibangun dengan fokus pada user experience dan performa.

## Fitur Utama

- Sistem pembayaran terintegrasi (Stripe)
- Manajemen inventory real-time
- Dashboard admin analitik
- Search & filter produk
- Responsive design mobile-first

## Tech Stack

- **Frontend:** React, Redux, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Payment:** Stripe API
