# Task Management App

Aplikasi manajemen tugas dengan kolaborasi real-time.

## Fitur Utama

- Kolaborasi tim real-time (Socket.io)
- Notifikasi push & in-app
- Sistem tracking progress
- Drag-and-drop kanban board
- Assign task & deadline

## Tech Stack

- **Frontend:** Vue.js, Pinia
- **Backend:** Express, Socket.io
- **Database:** PostgreSQL
